# 3. نظام البطاقات والدفع | Payment Cards System

> هذا هو نظام الدفع الأساسي — بسيط وذكي

---

## الفكرة

الطبيب يولّد **أكواد مشفرة** من لوحة التحكم. كل كود = بطاقة دفع لاستشارة واحدة.
المريض يدخل الكود عند الحجز → النظام يتحقق → يتم الحجز.

---

## أنواع البطاقات

| النوع | العملة | الفئة المستهدفة | مثال السعر |
|-------|--------|-----------------|-----------|
| يمني | ريال يمني (YER) | مرضى اليمن | 5,000 - 15,000 ر.ي |
| أمريكي | دولار (USD) | مرضى أمريكا | $20 - $50 |
| روسي | روبل (RUB) | مرضى روسيا | 1,500 - 3,000 ₽ |
| مجاني | — | عروض مجانية | $0 |

---

## هيكل البطاقة (الكود)

```
شكل الكود: DRM-XXXX-XXXX-XXXX
مثال:       DRM-A7K2-M9P4-X3B1

DRM       = بادئة ثابتة (Dr. Massoudi)
XXXX×3    = أحرف وأرقام عشوائية مشفرة (12 حرف)
```

## جدول قاعدة البيانات

```typescript
export const paymentCards = pgTable('payment_cards', {
  id:           uuid('id').primaryKey().defaultRandom(),
  code:         varchar('code', { length: 20 }).unique().notNull(),
  // 'DRM-XXXX-XXXX-XXXX'
  
  type:         varchar('type', { length: 10 }).notNull(),
  // 'yer' | 'usd' | 'rub' | 'free'
  
  amount:       decimal('amount', { precision: 10, scale: 2 }).default('0'),
  currency:     varchar('currency', { length: 3 }).notNull(),
  // 'YER' | 'USD' | 'RUB' | 'FREE'
  
  status:       varchar('status', { length: 15 }).default('active'),
  // 'active' | 'used' | 'expired' | 'revoked'
  
  targetRegion: varchar('target_region', { length: 20 }),
  // 'yemen' | 'usa' | 'russia' | 'all'
  
  usedBy:       uuid('used_by').references(() => patients.id),
  appointmentId: uuid('appointment_id').references(() => appointments.id),
  
  expiresAt:    timestamp('expires_at'),
  usedAt:       timestamp('used_at'),
  createdAt:    timestamp('created_at').defaultNow(),
  
  // بيانات إضافية
  batchId:      varchar('batch_id', { length: 50 }),
  // لتجميع البطاقات المولّدة معاً
  note:         text('note'),
  // ملاحظة الطبيب
});
```

## جدول قاعدة البيانات — العروض

```typescript
export const promotions = pgTable('promotions', {
  id:           uuid('id').primaryKey().defaultRandom(),
  
  titleAr:      varchar('title_ar', { length: 255 }).notNull(),
  titleEn:      varchar('title_en', { length: 255 }).notNull(),
  titleRu:      varchar('title_ru', { length: 255 }).notNull(),
  
  descriptionAr: text('description_ar'),
  descriptionEn: text('description_en'),
  descriptionRu: text('description_ru'),
  
  isActive:     boolean('is_active').default(false),
  promoType:    varchar('promo_type', { length: 20 }).default('free'),
  // 'free' | 'discount'
  
  maxUses:      integer('max_uses').default(20),
  currentUses:  integer('current_uses').default(0),
  
  showOnPages:  jsonb('show_on_pages').default('["home", "book"]'),
  
  startsAt:     timestamp('starts_at'),
  endsAt:       timestamp('ends_at'),
  createdAt:    timestamp('created_at').defaultNow(),
});
```
