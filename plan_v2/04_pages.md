# 6. تفصيل الصفحات الرئيسية

## 6.1 الصفحة الرئيسية (Landing Page)

**الأقسام:**
1. **Hero Section** — صورة الطبيب + عنوان + زر "احجز الآن"
2. **بانر العرض المجاني** (إذا مفعّل من اللوحة) — "استشارة مجانية!"
3. **Quick Stats** — سنوات الخبرة، عدد المرضى، التخصص
4. **About Snippet** — مقدمة + رابط "اقرأ أكثر"
5. **التخصصات** — بطاقات مع أيقونات
6. **كيف يعمل النظام** — 4 خطوات: سجّل → احصل على كود → احجز → استشر
7. **Availability Banner** — "متاح الآن" أو الموعد القادم
8. **CTA** — زر حجز نهائي + واتساب + تيليغرام
9. **Footer**

## 6.3 صفحة الحجز (Booking Wizard)

```
الخطوة 1: تسجيل الدخول
├── إدخال رقم الهاتف أو الإيميل
├── التحقق من وجود المريض + أنه معتمد
├── إرسال OTP (Telegram أولاً، SMS احتياطي)
└── خطأ: "غير مسجّل" → رابط لصفحة التسجيل

الخطوة 2: اختيار التاريخ
├── تقويم تفاعلي (الأيام المتاحة فقط)
├── عرض التوقيتين: توقيت المريض + موسكو
└── الأيام المغلقة رمادية

الخطوة 3: اختيار الوقت
├── فترات متاحة (30 دقيقة)
├── كل فترة تظهر بالتوقيتين
└── المحجوزة غير قابلة للنقر

الخطوة 4: إدخال كود البطاقة
├── إدخال الكود: DRM-XXXX-XXXX-XXXX
├── التحقق الفوري (صالح / غير صالح / منتهي)
├── عرض قيمة البطاقة وعملتها
└── أو: "استشارة مجانية" إذا كان عرض مفعّل

الخطوة 5: التأكيد
├── ملخص: التاريخ، الوقت (بالتوقيتين)، المدة، الكود
├── ملاحظات للطبيب (اختياري)
├── رفع ملف طبي (اختياري)
└── زر "تأكيد الحجز"

الخطوة 6: النجاح
├── رسالة نجاح + تفاصيل الموعد
├── إيميل تأكيد للمريض
└── إشعار تيليغرام فوري للطبيب
```

## 6.4 بوابة المريض (/patient)

```
تسجيل دخول: هاتف + OTP

بعد الدخول:
├── مواعيدي القادمة (مع رابط الاجتماع + التوقيتين)
├── مواعيدي السابقة
├── ملفاتي الطبية (رفع/تحميل)
├── إلغاء موعد (قبل X ساعة)
└── طلب تغيير موعد
```
