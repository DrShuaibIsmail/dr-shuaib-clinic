# 9. المصادقة والأمان

## المرضى
```
الدخول: رقم هاتف + OTP (4-6 أرقام)
OTP عبر: Telegram أولاً (مجاني) → SMS احتياطي
الجلسة: 7 أيام
```

## الطبيب (Admin)
```
الدخول: إيميل + كلمة مرور
2FA: عبر تيليغرام (اختياري)
الجلسة: 30 يوم
```

## الأمان
```
- HTTPS إلزامي
- Rate Limiting: 5 OTP / 15 دقيقة
- CSRF + Zod validation
- Drizzle ORM (prepared statements)
- Admin routes محمية بـ middleware
- بيانات المرضى مشفرة
- أكواد البطاقات: تشفير قوي (crypto.randomBytes)
```

# 10. API Endpoints

## Public
```
POST /api/auth/verify-patient        التحقق من المريض
POST /api/auth/send-otp              إرسال OTP
POST /api/auth/verify-otp            التحقق
POST /api/register                   تسجيل مريض جديد
GET  /api/availability?date=...      الأوقات المتاحة
POST /api/cards/verify               التحقق من كود البطاقة
POST /api/appointments/book          حجز موعد
GET  /api/appointments/my            مواعيدي
PUT  /api/appointments/:id/cancel    إلغاء
POST /api/files/upload               رفع ملف طبي
GET  /api/promotions/active          العرض المفعّل حالياً
```
